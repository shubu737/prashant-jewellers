# Prashant Jewellers

Luxury jewellery showcase website built with Next.js App Router and Tailwind CSS.

## Features

- Premium home page with hero, collections, best sellers, testimonials, and CTA
- Collection page with filters and smooth hover interactions
- Product detail pages with image gallery, contact CTA, and SEO metadata
- About and Contact pages with Google Map embed and local store details
- Mobile-first responsive design with sticky WhatsApp/Call actions

## Setup

1. Open the project folder:
   ```bash
   cd prashant-jewellers
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Open `http://localhost:3000`

## Deploy

Deploy to Vercel from this folder. Vercel detects Next.js automatically.

## Folder structure

- `app/` – Next.js App Router pages and layout
- `components/` – reusable UI components
- `lib/` – product data and helpers
